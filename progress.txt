## 2026-09-30 - Issue #44: Outfit harmony classifier

New `colorspace/OutfitHarmony.kt`: `OutfitHarmony.classify(colorsArgb, wheel)` for 2-8 colors
returns `OutfitHarmonyResult(level WORKS/BORDERLINE/CLASHES, scheme, oddOneOutIndex)`. No UI yet.
Colors under HCT chroma 16 are neutral and ignored; 0-1 chromatic colors = Works/NEUTRAL. Hues are
compared on the user's wheel via the new `ColorWheelStrategy.wheelHue` (HCT hue -> wheel position;
the piecewise map's forward direction), so Traditional/Screen agree with the Objects suggestions.
Schemes, tightest that fits wins: Tonal (arc <= 15), Analogous (arc <= 60), Complementary (split
at the two largest gaps; each cluster <= 30 wide, centers 180 +/- 25 apart). Otherwise the nearest
scheme within `BORDERLINE_MARGIN` (15) is Borderline, else Clashes; the odd one out is the single
chromatic color whose removal makes the rest Work (scheme = what the rest fits), null if none or
several (e.g. triads, two clashing colors). Tolerances in `OutfitHarmonyConfig`.
Note: Tonal is never the Borderline scheme, since a near-tonal set always fits Analogous.

Test: `OutfitHarmonyTest` (neutrals, each scheme, wrap-around at 0, borderline analogous/
complementary, clash with/without odd one out, yellow+blue and red+green across wheels, the RYB
wheel turning a tonal pair analogous, size limits). `./gradlew :colorspace:test` passes.

## 2026-09-30 - Issue #41: Camera pinch to zoom

Grilled with the user, spec written into the issue. The shared `CameraViewfinder` (so Rate
Clothing, Match Object and Find my season) zooms with `cameraControl.setZoomRatio`, so the capture
and its center box match the preview. New `ui/common/CameraZoom.kt`: pure `nextZoomRatio(current,
scale, max)` (clamped to 1x..`maxZoomRatio`, uncapped, never below 1x even with an ultra-wide) and
`Modifier.pinchToZoom`, which watches the Initial pass on the viewfinder Box: once a second finger
lands the gesture is consumed before the WB/exposure sliders see it (and stays consumed after one
finger lifts), while one-finger drags pass through. Zoom resets to 1x on every bind (lens switch,
new screen, retake). No reset gesture. A "2.3×" chip in the hint's style (`viewfinderLabel`) sits
above the shutter while pinching and fades 1s after release (`zoomActivity` counter re-triggers
it); it is a polite live region. TalkBack: the preview is a "Camera preview" node with custom
actions Zoom in / Zoom out (×1.5 / ÷1.5, same clamps).

Test: `CameraZoomTest` (multiply, 1x floor, device max, max below 1x, action round trip).
`./gradlew :colorspace:test :app:testDebugUnitTest assembleDebug lintDebug` all pass (lint: same
15 warnings); gesture, chip and slider handoff not tried on a device.
