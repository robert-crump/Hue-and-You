## Agent skills

### Issue tracker

Issues live in GitHub Issues on robert-crump/Hue-and-You (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Only `ready-for-agent` and `ready-for-human` are in use; the other triage roles have no label. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
